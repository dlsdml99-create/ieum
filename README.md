## 이음은 이런 앱이에요

여행 중에 **듣기 · 말하기 · 보기** 세 버튼으로 외국 사람과 이야기해요. 번역은 **폰 안에서** 해서, 언어마다 번역 팩을 한 번 받으면 인터넷 없이도 돼요.

| 기능 | 설명 |
| --- | --- |
| 👂 듣기 | 상대가 한 말을 듣고 한국어로 보여줘요 |
| 🗣 말하기 | 한국어로 말하면 상대 언어로 바꿔서 소리 내 읽어줘요 |
| 👁 보기 | 간판·메뉴판 사진 속 글자를 번역해요 |
| 📷 카메라로 비추기 | 셔터 없이, 비추는 동안 글자 위에 번역이 겹쳐 보여요 |
| 🔁 마주보기 | 폰을 테이블에 놓으면 위쪽이 상대 쪽으로 뒤집히고, 내 말이 끝나면 상대 말을 바로 들어요 |
| 💬 바로 대답 | 상대 말이 번역되면 네·아니요·다시 한번요·천천히요·감사해요를 누르기만 하면 돼요 |
| 🧾 메뉴판 주문 | 메뉴판을 찍고 먹을 것과 개수만 누르면 주문 문장을 크게 보여주고 읽어줘요 |
| 💱 가격 옆에 원화 | 사진 속 가격에 "≈ 6,200원"을 붙여요. 통화는 지금 있는 나라로, 환율은 하루 한 번 새로 받아요 |
| 📍 주소 카드 | 숙소 주소를 한 번 찍어 두면 택시에서 버튼 한 번으로 크게 보여줘요 |
| 🆘 위급 카드 | "도와주세요"를 그 나라 말로 크게 보여주고, 그 나라 긴급 번호와 영사안전콜센터를 바로 눌러요 |
| ⏱ 자주 쓰는 말 | 화장실·계산·추천 같은 말을 한 번 눌러서 바로 읽어줘요 |
| 📲 홈 화면 위젯 | 듣기·말하기·보기를 홈 화면에서 바로 열어요 |
| ⇄ 언어 바꾸기 | 가운데 화살표를 누르면 나와 상대 언어가 바로 바뀌어요 (19개 언어) |

## 이번 업데이트 내용

업데이트 내용은 [최신 릴리스](https://github.com/dlsdml99-create/ieum/releases/latest)에서 볼 수 있어요. 앱을 켤 때 새 버전이 있으면 "새 버전이 있어요" 창이 뜨고, **업데이트**를 누르면 파일이 받아져요. 덮어 설치해도 기록과 설정은 그대로 남아요.

## 설치하는 법
1. 안드로이드 폰에서 맨 위 **이음 다운로드**를 눌러요.
2. 다운로드가 끝나면 알림이나 **내 파일 → 다운로드**에서 `ieum.apk`를 눌러요.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와요.
4. **설치**를 눌러요. Play 프로텍트 경고가 뜨면 **세부정보 더보기 → 무시하고 설치**를 눌러요.
